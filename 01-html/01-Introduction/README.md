# HTML Introduction

## What is HTML?

**HTML (HyperText Markup Language)** is the standard markup language used to create the **structure of web pages**.

HTML defines the content and layout of a webpage by using **tags** to describe elements such as headings, paragraphs, images, links, tables, and forms.

> HTML provides the structure of a webpage. It does **not** control the design or functionality.

---

## Breaking Down HTML

### HyperText

HyperText refers to text that can connect one document to another using **hyperlinks**.

Example:

```html
<a href="https://www.google.com">Google</a>
```

When the link is clicked, the browser navigates to another webpage.

---

### Markup

Markup means **adding tags to content** so that the browser understands what each piece of content represents.

Example:

```html
<h1>Welcome</h1>

<p>This is a paragraph.</p>
```

The browser understands:

- `<h1>` → Main Heading
- `<p>` → Paragraph

Without markup, the browser would not know how the content should be displayed.

---

### Language

HTML follows a defined set of rules and syntax.

For example:

```html
<h1>Hello World</h1>
```

is valid HTML.

Incorrect syntax can lead to unexpected results.

---

## Is HTML a Programming Language?

**No.**

HTML is a **markup language**, not a programming language.

Programming languages can:

- Store variables
- Perform calculations
- Make decisions
- Execute loops
- Define functions

HTML cannot perform any of these tasks.

Instead, HTML only describes the structure of a webpage.

---

## Purpose of HTML

HTML is used to structure web pages by defining elements such as:

- Headings
- Paragraphs
- Images
- Hyperlinks
- Lists
- Tables
- Forms
- Buttons
- Videos
- Audio
- Sections

Every webpage on the internet uses HTML.

---

## HTML, CSS, and JavaScript

Modern websites are built using three core technologies.

| Technology | Purpose |
|------------|---------|
| HTML | Creates the structure |
| CSS | Styles the webpage |
| JavaScript | Adds functionality and interactivity |

Example:

- HTML creates a button.
- CSS styles the button.
- JavaScript makes the button perform an action when clicked.

---

## How HTML Works

When you create an HTML file and open it in a web browser, the following process occurs:

```
HTML File
      │
      ▼
Browser Reads HTML
      │
      ▼
Browser Understands HTML Tags
      │
      ▼
Creates the Webpage
      │
      ▼
Displays the Page
```

Browsers such as Chrome, Firefox, Edge, and Safari are responsible for interpreting HTML.

## Why Learn HTML First?

HTML is the foundation of frontend development.

Before learning CSS or JavaScript, you must understand how webpages are structured.

Without HTML:

- CSS has nothing to style.
- JavaScript has nothing to manipulate.

## Key Terms

| Term | Meaning |
|------|---------|
| HTML | HyperText Markup Language |
| HyperText | Text connected through hyperlinks |
| Markup | Tags that describe content |
| Tag | A keyword enclosed within angle brackets (`<>`) |
| Browser | Software that renders HTML into a webpage |

## Summary
