Meta Tags Demo

What's in This Page's <head>

Meta Tag What It Does
<meta charset="UTF-8"> Character encoding — supports all languages and emojis
<meta name="viewport"> Makes the page responsive on mobile devices
<title> The text shown in the browser tab
<meta name="description"> Appears in search engine results below the title
<meta name="author"> Identifies who wrote the page
<meta name="robots"> Tells search engines whether to index this page
<meta property="og:*"> Controls the preview card when sharing on social media
<meta name="twitter:*"> Controls the preview card specifically on Twitter/X
