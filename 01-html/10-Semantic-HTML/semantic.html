Why Semantic HTML Changed How I Write Code

Published on August 28, 2025

The Problem with Div Soup

When I started, every element was a <div> with a class name. The code worked, but it was hard to read and impossible for screen readers to navigate properly. Switching to semantic tags like <header>, <nav>, and <article> made everything cleaner.

The Biggest Benefits I've Noticed

  1. Readability — I can scan my own code and immediately understand the structure.
  2. Accessibility — Screen readers can build a navigable outline of the page.
  3. SEO — Search engines give more weight to content in meaningful tags.
Quick reference: which tag to use when?
  • <header> — Page or section intro
  • <nav> — Main navigation
  • <main> — Core content (one per page)
  • <article> — Standalone content
  • <section> — Themed grouping
  • <aside> — Related side content
  • <footer> — Closing info
