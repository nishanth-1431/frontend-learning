Key Takeaways

  • Use descriptive link text — avoid "click here"
  • Always add rel="noopener noreferrer" with target="_blank"
  • Use #id to create bookmark links within the same page
  • Relative paths for internal links, absolute paths for external ones
  • The download attribute triggers a download instead of navigation
